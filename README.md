# Qwen Agent — установка и обновления

## Скачать приложение для Windows x64

**[Скачать INSTALL.cmd](https://github.com/BahtukOnce/qwen-agent-releases/releases/latest/download/INSTALL.cmd)**

1. Закройте Qwen Agent, если он уже запущен.
2. Запустите INSTALL.cmd и выберите прежнюю папку приложения либо новую пустую папку.
3. Дождитесь скачивания: готовая сборка включает Python, Qt и Chromium. Установщик проверит SHA-256 и запустит приложение.

Устанавливать Python и распаковывать ZIP вручную не нужно. Для подключения модели нужен ваш аккаунт Open WebUI.

## Последующие обновления

В приложении нажмите **«Проверить обновления»** и подтвердите установку новой версии. Она установится в ту же папку с резервной копией предыдущей. Вход и профиль браузера хранятся отдельно.

Если установлена версия 0.2.x, один раз выполните установку через INSTALL.cmd: старые версии обращались к другому, закрытому каналу. Начиная с 0.3.0 используется этот публичный канал.

Не храните рабочие проекты внутри папки программы: при обновлении она заменяется целиком. Предыдущая папка сохраняется рядом для отката.
